# Changelog

Versions follow [Semantic Versioning](https://semver.org). Until 1.0, a minor version
may change how things work.

## 0.1.0 - 2026-10-24

The first release.

- Finds plugins in folders and runs the ones that are switched on; folders that gain or lose a plugin are noticed.
- Plugins can bring windows, IPC calls, a page of settings and an island for the bar.
- `api = 1`: the version of the plugin interface.
